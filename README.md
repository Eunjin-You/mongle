# 몽글작업실 (Mongle Studio)

## 1. 질문 한 문장
**AI 시대에 생산성이란 무엇일까?**

## 2. 질문과 조사
생성형 AI가 보편화되면서 소설 초안 작성, 작곡, 영상 제작처럼 과거에는 많은 시간이 필요했던 일도 프롬프트 한 번으로 빠르게 시도할 수 있게 되었다. AI가 작업하는 동안 사람은 기다리거나 쉬어도 된다. 그렇다면 **사람이 직접 일에 투입한 시간이 줄어드는 시대에, 생산성을 무엇으로 판단해야 할까?**

처음에는 ‘할 일을 완료하는 대신 지우는 투두리스트’, ‘오래 작업할수록 오히려 불이익을 주는 타이머’처럼 기존 생산성의 기준을 뒤집는 아이디어도 고민했다. 이후 기존 투두리스트와 프로젝트별 시간을 기록하는 **Toggl Track**을 참고하면서, 단순한 할 일 관리나 시간 측정만으로는 차별점을 만들기 어렵다는 점을 확인했다.

이에 생산성을 **얼마나 오래 일했는가**보다 **막연한 목표를 실제 행동으로 옮기고, 그 결과물을 계속 쌓아가는 과정**에서 찾기로 했다. AI가 결과물을 대신 만들어주는 것보다, 기술이 사람이 직접 창작을 시작하고 이어갈 수 있도록 돕는 데 집중했다.

## 3. 작품 소개 및 주요 기능
**몽글작업실**은 장기 창작 프로젝트를 시작하거나 꾸준히 이어가기 어려운 사람을 위한 웹앱이다. 현재 MVP는 소설 집필을 중심 사례로 사용하지만, 프로젝트 구조는 다른 창작 활동에도 적용할 수 있도록 설계했다.

- **Project → Phase → 첫 행동:** 큰 목표를 단계로 나누고, 질문을 통해 지금 당장 실행할 수 있는 작은 행동을 정한다.
- **컨디션 기반 작업 배분:** 사용자가 오늘의 상태를 선택하면 작업 개수와 집중 시간을 제안한다. 최종 결정은 사용자가 한다.
- **집중과 기록:** 선택형 타이머로 작업하고, 실제로 만든 결과물과 다음에 할 첫 행동을 남긴다.
- **이어서 시작하기:** 다음 방문 때 이전 작업과 다음 행동을 보여주어 재시작의 부담을 줄인다.
- **프로젝트의 의미 강조:** 프로젝트 등록 직후 ‘작업실 개관’ 화면을 통해 사용자가 자신의 창작을 중요한 작업으로 인식하도록 연출한다.

화면마다 하나의 주요 행동에 집중하도록 구성했으며, 따뜻한 색감과 작업실 이미지를 사용했다.

## 4. AI USE NOTE — AI 활용 과정
컨셉트를 구체화하는 단계에서는 Claude AI에게 내가 생각하고 있는 모호한 방향성에 대해 질문을 계속 던져달라고 요청하며 스스로 생각해보고, 여러 가지 옵션들을 산출하였다. 이후 그러한 여러가지 옵션들을 초안으로 하여 ChatGPT를 기획·개발 협업 도구로 활용했다. ‘AI 시대의 생산성’이라는 질문에서 출발해 해당 옵션들 비교했고, 대화를 거치며 감정적 보상 중심 앱 → 프로젝트 중심 앱 → 시작과 지속을 돕는 앱으로 방향을 좁혔다. 이어 사용자 흐름, 질문형 작업 분해, 컨디션별 계획 배분을 함께 설계했다.

구현 단계에서는 ChatGPT가 **HTML·CSS·JavaScript 초안과 수정본**을 작성하도록 했다. 처음에는 JavaScript가 화면 구성까지 많이 담당해 직접 수정하기 어려웠기 때문에, HTML의 `template`과 읽기 쉬운 CSS 중심으로 구조를 다시 정리하도록 요청했다. 이미지 분할·배치, 글꼴 크기 조정, 기본 동작 점검에도 AI를 활용했다. **핵심 문제의식과 제품 방향, 디자인·기능에 대한 판단과 수정 요청은 직접 수행**했다.

## 5. 실패와 배운 점
초기에는 귀여운 캐릭터 보상, 페널티, 음악 추천 등 기능이 늘어나면서 **무엇을 해결하려는 앱인지 흐려졌다.** 또한 시간 추적 기능은 이미 유사 서비스가 있어 차별점이 되기 어려웠다. 이를 통해 기능의 수보다 **명확한 사용자 문제와 일관된 핵심 흐름**이 중요하다는 점을 배웠다.

개발 과정에서는 AI가 작성한 코드가 작동하더라도, **내가 이해하고 수정하기 어려우면 완성도 있는 작업이라 보기 어렵다**는 점을 느꼈다. 따라서 구현 방식 자체를 HTML·CSS 중심으로 다시 조정했다. 현재 버전은 브라우저 저장소를 사용하는 MVP로, 실제 사용자 대상의 장기적인 효과 검증은 아직 이루어지지 않았다.

**결론적으로 이 프로젝트가 제안하는 생산성은 ‘더 많은 일을 더 빨리 처리하기’가 아니라, 사람이 중요하게 생각하는 일을 실제로 시작하고 끝까지 이어갈 수 있게 하는 능력이다.**
